# 🩺 ดูแล (Doo-Lae) - Generations Care & Transit

แอปพลิเคชันดูแลคนที่คุณรักและการเดินทางด้วยหัวใจ (Generations Care & Transit) สำหรับครอบครัวที่ต้องการผู้ดูแลผู้สูงอายุ พี่เลี้ยงเด็กเล็ก และบริการรถรับส่งที่ไว้วางใจได้ พัฒนาด้วย **Vue 3 + Vite** รองรับการใช้งานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

### 📥 ลิงก์ดาวน์โหลดโปรแกรมที่จำเป็น:

   - 🍏 **สำหรับเครื่อง Mac (macOS):** [ดาวน์โหลด Node.js สำหรับ Mac (.pkg)](https://nodejs.org/en/download)
   - 🪟 **สำหรับเครื่อง Windows:** [ดาวน์โหลด Node.js สำหรับ Windows (.msi)](https://nodejs.org/en/download)

2. **ดาวน์โหลดไฟล์โปรเจกต์ ดูแล (Doo-Lae):**

## 🚀 วิธีติดตั้งและเริ่มใช้งานแบบเข้าใจง่าย

### วิธีที่ 1: ดับเบิลคลิกรันอัตโนมัติ (ง่ายที่สุดสำหรับ Mac)

1. เปิดโฟลเดอร์ `frontend`
2. ดับเบิลคลิกที่ไฟล์ **`start_server.command`**
3. ระบบจะทำการตรวจสอบและติดตั้งโปรแกรมให้อัตโนมัติ พร้อมเปิดเซิร์ฟเวอร์ให้ทันที!

---

### วิธีที่ 2: รันผ่าน Terminal / Command Line

หากต้องการรันคำสั่งด้วยตัวเอง ให้ทำตาม 3 ขั้นตอนง่ายๆ ดังนี้:

#### ขั้นตอนที่ 1: เปิด Terminal ไปที่โฟลเดอร์ของโปรเจกต์

เปิดโปรแกรม **Terminal** (บน Mac) หรือ **Command Prompt** (บน Windows) แล้วพิมพ์คำสั่งเพื่อเข้าไปยังโฟลเดอร์ `frontend`:

```bash
cd /เส้นทางโฟลเดอร์/Doolae-Project/frontend
```

_(เคล็ดลับ: พิมพ์ `cd ` แล้วลากโฟลเดอร์ `frontend` มาวางในหน้าต่าง Terminal ได้เลย)_

#### ขั้นตอนที่ 2: ติดตั้ง Dependencies (ทำเฉพาะครั้งแรก)

พิมพ์คำสั่งนี้เพื่อดาวน์โหลดแพ็กเกจที่จำเป็น:

```bash
npm install
```

_(รอระบบดาวน์โหลดสักครู่จนขึ้นข้อความเสร็จสิ้น)_

#### ขั้นตอนที่ 3: เริ่มต้นรันโปรแกรม (Start Dev Server)

พิมพ์คำสั่ง:

```bash
npm run dev
```

เมื่อสำเร็จ หน้าจอจะแสดงข้อความลักษณะนี้:

```text
  VITE v6.x.x  ready in 150 ms

  ➜  Local:   http://localhost:8080/ [บนเครื่องตัวเอง]
  ➜  Network: http://192.168.1.xx:8080/ [สำหรับมือถือและในเครือข่ายเดียวกัน]
```

## 📱 วิธีเปิดดูบนมือถือและคอมพิวเตอร์

### 💻 1. เปิดบนคอมพิวเตอร์

- เปิดเบราว์เซอร์ (Google Chrome, Safari หรือ Edge)
- พิมพ์ที่อยู่เว็บ: **`http://localhost:8080`** แล้วกด Enter

### 📱 2. เปิดบนโทรศัพท์มือถือหรือแท็บเล็ต

- เชื่อมต่อมือถือเข้ากับ **Wi-Fi วงเดียวกับคอมพิวเตอร์**
- เปิดเบราว์เซอร์บนมือถือ (Safari หรือ Chrome)
- พิมพ์ที่อยู่ตามที่แสดงในบรรทัด `Network:` ของหน้าจอ Terminal เช่น:
  ```
  http://192.168.1.15:8080
  ```

## 💡 คู่มือการใช้งานฟังก์ชันหลัก

แอปพลิเคชัน **ดูแล (Doo-Lae)** มี 2 โหมดหลัก สามารถสลับใช้งานได้ตลอดเวลา:

### 1. 👤 โหมดผู้ใช้บริการ (Customer / Family)

เหมาะสำหรับครอบครัวที่ต้องการค้นหาและจ้างผู้ดูแล:

- **เลือกหมวดบริการ**:
  - 👵 **ดูแลผู้สูงอายุ & พักฟื้น (Senior Care)**: บันทึกสุขภาพ รายงานการพาพบแพทย์
  - 👶 **ดูแลเด็กเล็ก (Child Care)**: พี่เลี้ยงเด็ก และกล้องถ่ายทอดสด Live Nanny Cam
  - 🚗 **รถรับส่ง Transit**: รถรับส่งผู้สูงวัยและเด็ก พร้อมระบบพิกัด GPS ติดตามตลอดเส้นทาง
- **ค้นหาและจองผู้ดูแล**: เลือกระยะเวลา คำนวณราคา พร้อมสแกนจ่ายผ่าน PromptPay QR
- **ติดตามงานแบบเรียลไทม์**:
  - แผนที่ **GPS Real-time** บอกตำแหน่งคนขับ/ผู้ดูแลและเวลาที่จะถึง
  - **เช็คลิสต์ดูแลประจำวัน**: ติ๊กดูรายการที่ทำเสร็จแล้ว และกดปุ่ม `+ เพิ่มรายการ` ได้เอง
  - **แชทสด (Live Chat)**: พิมพ์ข้อความหรือกดเลือกข้อความด่วนเพื่อคุยกับผู้ดูแล
  - **กล้องสดดูเด็ก**: สตรีมภาพแบบสด พร้อมปุ่มพูดคุย 2 ทางและถ่ายรูป

### 2. 🧑‍⚕️ โหมดผู้ดูแล (Provider / Caregiver)

เหมาะสำหรับพยาบาล พี่เลี้ยง และคนขับรถ:

- **เปิด/ปิดสถานะรับงาน**: สลับสวิตช์ `🟢 Online` เพื่อรับงานใหม่ หรือ `🔴 Offline` เมื่อพักผ่อน
- **ดูรายได้สะสม**: แสดงสรุปยอดเงินค่าจ้างประจำวันและจำนวนงานที่เสร็จสิ้น
- **รับงานใหม่**: ดูกล่องข้อเสนองานที่ส่งเข้ามา กด `กดรับงาน` หรือ `ข้ามงานนี้`
- **เครื่องมือบันทึกสุขภาพ (เมื่อรับงานแล้ว)**:
  - 🩺 **บันทึกสัญญาณชีพ**: ความดันโลหิต, ระดับน้ำตาล, ชีพจร, อุณหภูมิ
  - 🏥 **รายงานการพาพบแพทย์**: สรุปคำวินิจฉัยแพทย์ และบันทึกยาที่ปรับเปลี่ยน
  - 🍼 **บันทึกกิจกรรมเด็ก**: ป้อนนม, นอนกลางวัน, เปลี่ยนผ้าอ้อม
- **ติ๊กเช็คลิสต์ & ส่งงานเสร็จสิ้น**: ติ๊กงานที่ทำเสร็จ และกดยืนยันทำงานเสร็จเพื่อรับเงิน

### 3. 🚨 ศูนย์ช่วยเหลือฉุกเฉิน (SOS 24 ชม.)

- กดปุ่ม **SOS** สีแดง เพื่อเข้าสู่ศูนย์ช่วยเหลือเร่งด่วน
- โทรออกสายด่วน **1669 กู้ชีพฉุกเฉิน** หรือโทรหาญาติทันที
- ส่งสัญญาณพิกัด GPS อัตโนมัติไปยังทีมช่วยเหลือ

### 4. 🌐 การปรับแต่งการแสดงผล

- **สลับภาษา**: กดปุ่ม `🌐 TH / EN` ที่มุมบนขวาเพื่อเปลี่ยนเป็นภาษาไทยหรือภาษาอังกฤษ
- **สลับโหมดหน้าจอ**: กดปุ่ม `📱 กรอบมือถือ` หรือ `💻 โหมดเว็บ` เพื่อปรับให้เหมาะกับขนาดหน้าจอ

## ❓ การแก้ปัญหาเบื้องต้นที่พบบ่อย (FAQ)

### Q1: รันคำสั่ง `npm` แล้วขึ้นข้อความว่า "command not found"

**วิธีแก้:** คุณยังไม่ได้ติดตั้ง Node.js ให้เข้าไปดาวน์โหลดและติดตั้งที่ [https://nodejs.org/](https://nodejs.org/) แล้วปิด Terminal เปิดใหม่อีกครั้ง

### Q2: เปิดดูบนมือถือไม่ได้ ขึ้นหน้าเว็บหมุนค้าง

**วิธีแก้:**

1. ตรวจสอบว่าโทรศัพท์มือถือและคอมพิวเตอร์ต่อ **Wi-Fi ชื่อเดียวกัน** หรือไม่
2. ตรวจสอบว่าพิมพ์เลข IP Address ถูกต้องครบถ้วนรวมถึงพอร์ต `:8080` (เช่น `http://192.168.1.51:8080`)

### Q3: ต้องการปิดการทำงานของเซิร์ฟเวอร์

**วิธีแก้:** ในหน้าต่าง Terminal ให้กดปุ่ม **`Ctrl` + `C`** บนคีย์บอร์ด
